# Chain-of-Scent

Does an LLM agent designing odorant molecules actually reason about chemistry,
or does it narrate over a hill-climb?

The project tests that by intervention rather than by comparing prose to a
saliency map. When the agent says "the aldehyde gives it a green note", we
delete the aldehyde and check whether green actually drops. Where the edited
molecule also exists in the human-labelled set, we check against the human
labels instead of a model.

Everything is CPU-only apart from the LLM API calls.

## Install

```bash
pip install -r requirements.txt
```

`anthropic` is only needed for real runs; the whole pipeline runs offline
without it.

## Quickstart

```bash
# 1. data, oracle, and positive controls   (~2 min, no API key)
python scripts/01_prepare.py

# 2. dry run with the mock agent, no API key, checks every code path
python scripts/02_run_agents.py --backend mock --n-targets 6 --rounds 4
python scripts/03_faithfulness.py --extractor rule
python scripts/05_analyze.py
```

Then the real thing:

```bash
export ANTHROPIC_API_KEY=...
rm results/runs.jsonl                       # start a clean log
python scripts/02_run_agents.py --backend anthropic --model claude-sonnet-5 \
    --n-targets 30 --rounds 6 --focus green
python scripts/03_faithfulness.py --extractor both --backend anthropic
python scripts/04_contamination.py --backend anthropic --n 100
python scripts/05_analyze.py
```

Rough cost for 30 targets x 5 arms x 6 rounds: a few hundred short calls.
Start with `--n-targets 5` and read the logs before scaling.

## What each piece does

| file | role |
|---|---|
| `cos/data.py` | curated GoodScents+Leffingwell set (4,983 molecules, 138 descriptors), Bemis-Murcko scaffold split |
| `cos/chem.py` | fingerprints, novelty, SA score, and the functional-group catalogue with its neutralising reactions |
| `cos/oracle.py` | the tool the agent calls: bagged logistic regression on Morgan counts, trained on train scaffolds only, reporting ensemble disagreement and nearest-neighbour similarity |
| `cos/targets.py` | target profiles sampled from held-out scaffolds |
| `cos/agent.py` | the design loop and its five arms |
| `cos/claims.py` | reasoning text to (group, descriptor, direction) triples, rule-based and LLM extractors |
| `cos/interventions.py` | the faithfulness test: grounding, ablation, specificity, placebo, human-label anchoring |
| `cos/contamination.py` | cold-recall memorisation probe |
| `cos/analysis.py` | tables, bootstrap CIs, figure |

## The five arms

The comparison between arms is the experiment. With a scoring oracle in the
loop, an agent improves by hill-climbing whether or not its reasoning means
anything, so "reasoning quality correlates with success" is uninterpretable
until these are on the table.

- **full** — reasoning then tool call, the system under test
- **no_reasoning** — proposals only, same feedback. If this matches `full`,
  the reasoning is decoration.
- **scrambled** — the agent's own reasoning is replaced in its context by
  reasoning written for a different target. If performance holds, the text is
  not load-bearing.
- **no_feedback** — reasoning, no oracle scores. Separates chemical prior from
  search.
- **random_mutation** — no LLM. RDKit edits, same round budget. The floor.

## The faithfulness test

For each extracted claim (molecule M, group G, descriptor D, direction):

1. **Grounding** — is G even present in M? Ungrounded claims are the cheapest
   unfaithfulness measure there is and they cost nothing to count.
2. **Ablation** — build M' by neutralising G with a minimal edit; measure
   `delta = p(D|M') - p(D|M)`. An "increase" claim predicts `delta < 0`.
3. **Specificity** — is |delta| for D unusual against the distribution of
   |delta| over all 138 descriptors under the same edit? A claim that moves
   everything explains nothing.
4. **Placebo** — repeat on a group in M the agent did *not* mention. If the
   placebo moves D as much, the claim is doing no work.
5. **Anchor** — where M and M' are both in the curated set, recompute from the
   human labels. Fewer cases, but these are the defensible ones.

`scripts/01_prepare.py` validates step 5 against known chemistry with no model
involved. Current output on the curated set:

| edit | pairs | loses descriptor |
|---|---|---|
| thiol removed, sulfurous | 76 | 0.76 |
| aldehyde removed, aldehydic | 75 | 1.00 |
| aldehyde removed, green | 75 | 0.96 |
| carboxylic acid removed, sour | 66 | 0.73 |
| alkene removed, green | 200 | 0.62 |
| phenol removed, phenolic | 21 | 0.59 |
| ester removed, fruity | 81 | 0.51 |

If those numbers ever collapse, the intervention machinery is broken and no
faithfulness number downstream is worth reading.

The mock agent is also a negative control. Its "reasoning" is generated by
template from randomly chosen groups and descriptors, and the pipeline scores
it at sign agreement 0.25 against a chance level of 0.5. A pipeline that
scored the mock agent as faithful would be measuring nothing.

## Reporting

Report all of this, including the parts that weaken the result:

- oracle held-out macro AUROC on the **scaffold** split (currently 0.70 for the
  fingerprint baseline; openpom's MPNN will be higher but was trained on the
  whole set, which breaks the split)
- the full arm table with paired bootstrap CIs, not just the full arm
- fraction of proposals far from the training set and the score/uncertainty
  correlations from `table_gaming.json`. High scores concentrated at low
  similarity and high ensemble disagreement means the agent found a hole in the
  proxy. Exclude those from success rates and report them as their own finding
- contamination summary, and faithfulness split by whether the molecule was
  recalled cold
- extractor agreement between the rule-based and LLM extractors
- oracle-anchored and human-anchored faithfulness separately, always

## Known limitations to state in the paper

- The oracle is a model, not ground truth. Only the anchored subset escapes
  this, and it is small.
- Ablation edits are minimal but not neutral. Removing a thiol changes size,
  logP and shape as well as the group. The placebo control bounds this; it does
  not eliminate it.
- The group catalogue is 14 entries. Claims about ring systems, stereochemistry
  and chain length are not testable as written. Report extraction coverage.
- Sign agreement conflates "the model is wrong about chemistry" with "the model
  is not using the reason it stated". The scrambled arm helps separate them;
  it does not settle it.
- No human panel. Nothing here is a claim about how a molecule actually smells.

## Data

Curated GoodScents + Leffingwell merge, downloaded on first run from openpom
(Barsainyan et al., replication of Lee et al., *Science* 2023,
doi:10.1126/science.ade4401). Cached in `data/`.
